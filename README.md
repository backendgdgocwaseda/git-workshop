# Git & GitHub Workshop
Welcome to the GDGoC Waseda Git/GitHub Workshop!

# Today's Goal
Work with your teammates to contribute to a shared
GitHub repository.

# Exercise 1: Your First Contribution
1. Fork the workshop repository (group leaders).
2. Invite your group members as collaborators.
3. Clone your group's repository.
4. Create your own branch.
5. Add a Python file inside the member_introduction folder.
6. Commit and push your changes.
7. Create a pull request.
8. Review and merge your team's contributions.

# Exercise 2: Merge Conflict Challenge
1. Create a new branch from the latest main.
2. Edit the team-motto.txt file.
3. Push your changes and open a pull request.
4. Resolve the conflict with your teammates!

Happy coding!
